# LinkedIn Prospection

MVP de prospection B2B human-in-the-loop.

## Objectif
Centraliser les prospects qualifiés, comprendre pourquoi ils matchent, identifier la bonne personne à contacter et préparer un message personnalisé. Les interactions LinkedIn restent manuelles.

## Pipeline
Découvert → Qualifié → À ajouter → Connecté → Message prêt → Contacté → Répondu

## Lancer
```bash
npm install
npm run dev
```

Puis ouvrir http://localhost:3000.
